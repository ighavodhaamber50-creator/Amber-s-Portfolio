# Amber's Portfolio

A personal portfolio website showcasing my web development projects, skills, and contact information.

## About the Project

This portfolio introduces me and presents selected websites and projects I've built while learning web development.

It includes an introduction, an About section, a project gallery, a skills section, and contact links.

* JavaScript
